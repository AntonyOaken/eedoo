## Подтверждённое ограничение передачи

Веб-версия приняла первые четыре маршрута целиком: 5, 5, 5 и 7 точек.
Передача длинного маршрута одним URL из 12 точек оставила лишь первые 10:
финиш у Смольного и остановка «Сквер Кикины Палаты» исчезли; маршрут завершился
у «Брусиловского сквера». Это неполный маршрут, его 7 км / 87 мин нельзя
сравнивать с полной прогулкой.

Исправленный экспорт делит его на две части с общей граничной точкой:
1. Астория → Брусиловский сквер: 10 точек, 7 км, 87 мин.
2. Брусиловский сквер → Сквер Кикины Палаты → Смольный собор: 3 точки, 1 км, 14 мин.

Публичные страницы второй проверки подтвердили все координаты, порядок и конечную
точку. Для веб-совместимости приложение передаёт максимум 10 точек всего в каждой
ссылке, без потери остановок. По просьбе пользователя экспорт на iPhone/iPad теперь
передаёт весь маршрут одной ссылкой, включая все остановки и финиш, даже при более
чем 10 точках. Пользователь проверит поддержку на своём устройстве. Работа в нативном
iOS приложении пока не проверена; веб-ограничение выше остаётся подтверждённым.

## Почему маршруты расходятся

1. По ссылке передаются упорядоченные координаты, а не линия маршрута: 2ГИС заново
   выбирает улицы, проходы, входы и переходы. Точное совпадение линии не гарантируется.
2. В режиме «По пути» часть наших остановок расположена возле линии, а не на ней.
   Экспорт делает их обязательными точками посещения; это способно добавить небольшой крюк.
3. Расчёты времени используют разные модели скорости и задержек. Их разница
   не равна разнице длины (пример: Новая Голландия).
4. Округление отображаемого расстояния 2ГИС мешает точно оценить разницу в метрах.

Точное перекрытие линий в процентах не измерялось: геометрия 2ГИС не извлекалась из
скрытых API или состояния сайта. Android/iOS, запуск голосового ведения и сценарий
отсутствующего приложения не проверены на реальных устройствах. Ссылки HTTPS
предусматривают веб-версию как fallback по документации 2ГИС.

Кнопка использует текущий выбранный вариант прогулки, сохраняет порядок остановок,
и для длинных маршрутов вне iPhone/iPad показывает явно подписанные части.
