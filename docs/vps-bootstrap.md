# Первоначальная установка на VPS

Назначение: пустой VPS; Ubuntu или Debian; SSH-пользователь с sudo. Сценарий ops/bootstrap-vps.sh устанавливает Docker Engine/Compose через официальный apt-репозиторий, клонирует приложение в /opt/poputi, генерирует пароли PostgreSQL и токен метрик, выполняет миграции/импорт каталога, запускает приложение и создаёт первую резервную копию. SSH-пароли в сценарий не передаются и не сохраняются.

## Запуск

На своём компьютере открыть терминал:

```bash
ssh SSH_USER@SERVER_IP
```

После входа:

```bash
curl -fSL https://raw.githubusercontent.com/AntonyOaken/eedoo/main/ops/bootstrap-vps.sh -o /tmp/poputi-bootstrap.sh
sudo bash /tmp/poputi-bootstrap.sh
```

Пароль SSH и при необходимости sudo вводится в терминале. Если curl отсутствует, загрузить файл с GitHub и скопировать через scp. `--dry-run` выводит план и характеристики сервера без установки. При неподдерживаемой ОС сценарий останавливается до установки.

Сценарий сохраняет существующий .env, не перезаписывает чужую папку /opt/poputi и прекращает обновление при изменённых Git-файлах. Повторный импорт того же снимка идемпотентен. Docker перезапускает сервисы после перезагрузки сервера. База и Redis не имеют публичных портов; Nginx слушает только 127.0.0.1:8080. Файрвол и настройки SSH не меняются.

## Проверка приложения

В отдельном локальном терминале:

```bash
ssh -N -L 8080:127.0.0.1:8080 SSH_USER@SERVER_IP
```

Открыть http://localhost:8080. Такое начало рассчитано на индивидуальную проверку через SSH-туннель. Тайлы карты по умолчанию берутся с OSM; перед публичным запуском задать выбранный собственный/договорной TILE_URL. Серверный Valhalla/Photon пока не настроены: маршруты вычисляет Web Worker, поиск работает по собственному каталогу. Фото нужно восстановить из сохранённого архива данных либо загрузить в настроенное S3-хранилище. Ни домен, ни публичный доступ этим сценарием не включаются.

Чтобы восстановить фотографии: скачать poputi-data.tar.gz из сохранённого комплекта на компьютер; передать `scp poputi-data.tar.gz SSH_USER@SERVER_IP:/tmp/`; на сервере выполнить `sudo tar -xzf /tmp/poputi-data.tar.gz -C /opt/poputi public/photos`. Для последующей загрузки в S3 настроить .env и запустить `sudo docker compose --profile tools run --rm tools pnpm media:upload` из /opt/poputi. Архив уже содержит work/catalog.json, но установщик сам создаёт актуальный снимок из исходников GitHub.

Журнал установки: /var/log/poputi-bootstrap.log. Статус: из /opt/poputi выполнить `sudo docker compose ps`; диагностика: `sudo docker compose logs --tail 100 app nginx`. Резервные копии находятся в /opt/poputi/backups; регулярное внешнее резервирование настраивается отдельно после проверки восстановления.
