# Происхождение миграции

Назначение: AntonyOaken/eedoo, основная ветка main. Исходная опубликованная версия Sites — 55; её последний коммит c2b6ce3. Подготовленный коммит миграции a1efa5c3dd2fbe8293fa7bce2ec08cdfa7d73b61 проверен сборкой Next.js и тестами.

GitHub получает текущее дерево исходников через GitHub API. Исходная история из 61 коммита плюс миграция сохранена отдельно в полном Git bundle. Она не подменяется синтетическими историческими коммитами. В сохранённом комплекте: poputi-source.tar.gz, poputi-data.tar.gz, poputi-history.bundle.part-00 и part-01, migration-status.md.

SHA-256 объединённого bundle: 51acc2900e1b4c4179494739d87f275c6d8be3e177a1bfcf80309f6ff5ba1b12. Чтобы восстановить историю, объединить части по порядку, выполнить git clone -b migration/self-hosted poputi-history.bundle. При желании её можно отправить отдельной веткой sites-history без перезаписи main.

Фото и экспорт каталога сохраняются отдельно от исходников и сборки; poputi-data.tar.gz распаковывается в корень проекта. В актуальном Git-дереве нет public/photos. В production каталог обслуживает PostgreSQL/PostGIS, фото — S3-совместимое хранилище. Провайдер S3 и VPS ещё не выбраны.

Локально прошли TypeScript, сборка Next.js, 41 JavaScript/TypeScript-тест и 13 Python-тестов. Не выполнялись запуск контейнеров, тест реальной PostgreSQL, S3 upload, браузерная проверка и нагрузочные ступени 100/300/1000. Эти этапы необходимы после выбора инфраструктуры.
