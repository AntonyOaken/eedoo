# Каталог Кургана: 2ГИС

Проверено 6 октября 2026 года. Это первый выборочный импорт, не полный каталог 2ГИС: 42 карточки проверены, 21 существующее место обновлено, 20 новых мест добавлено, 40 фотографий и 23 полных расписания сохранены.

В режимах «По пути» и «Не спешу» подтверждённые данные 2ГИС применяются после Google Maps и OSM. Отсутствующие поля остаются из предыдущих источников. «Покушать», режим фото, Петербург и Пхукет этим импортом не изменяются.

Сведения и фотографии уже лежат в каталоге и статических файлах сайта. Открытие карточки не вызывает запросов в 2ГИС. В карточках сохранены источник, дата проверки, автор фотографии и ссылка на галерею. Изображения уменьшены до 1400 px с сохранением пропорций; лицензия Creative Commons им не приписывается.

Полные недельные расписания включают выходные и обеденные перерывы. Посещение по записи, сезонные часы, санитарные дни и время работы кассы сохраняются отдельными примечаниями. Часы только на сегодня не выдаются за недельное расписание. Обычное закрытие после окончания рабочего дня не считается закрытием учреждения. Подтверждённо закрытые музеи остаются на карте, но не рекомендуются остановками.

Идентичность мест проверяется по названию, адресу и координатам ссылки «Маршрут». Неоднозначное совпадение памятника Д. Е. Пичугину отклонено: расстояние до сохранённой точки Google — 2876 м. Близко расположенные разные учреждения и памятники не объединяются только по расстоянию.

Сбор проведён последовательно через публичный интерфейс: поисковые списки, карточки, раскрытое расписание и фотогалереи. Прокси, обход капчи, скрытые API и ключи сайта не использовались. Поисковые списки иногда содержат рекламу и нерелевантные организации: они не импортированы. Обновление выполняется вручную, автоматический парсинг при открытии сайта не запускается.

Файлы: `kurgan-2gis-matches.json` — проверенные сопоставления; `kurgan-2gis-observations.json` — наблюдения публичных карточек; `kurgan-2gis-audit.json` — результаты и исключения. `lib/kurgan-2gis-places.json` — применяемые данные; `public/photos/kurgan/2gis` — сохранённые фото.

Для повторного построения из сохранённых наблюдений и фото:

```bash
python scripts/import-kurgan-2gis.py docs/kurgan-2gis-observations.json --date 2026-10-06
```

Это воспроизводит сохранённый срез, не получает новые данные из 2ГИС. Тесты парсера: `python -m unittest discover -s tests -p '*_test.py'`.
